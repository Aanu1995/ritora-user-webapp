Intelligence is now educational on each product today — and will power the Today's Suggestion pipeline when that ships. Rules live in Postgres, English-only. Other languages are produced at runtime by an LLM, cached per-string.

2 · How it works under the hood

Deterministic-first + LLM translation only

The safety verdict always comes from hardcoded-in-Postgres rules. The LLM's only job is turning English into whatever language the user asked for. Translations are cached by sha256(source) + language.

Backend data flow — POST /ingredients/analyze
Postgres ingredient_entries, ingredient_aliases, ingredient_category_patterns, ingredient_conflict_rules English-only. Seeded at boot from JSON.
→
Deterministic engine MatchingService → normalize INCI → alias → regex. AnalysisService → build actives + pairing guidance from rules.
→
TranslationService LRU (in-memory) + ingredient_translation_cache (Postgres). LLM only on cache miss. English passes through untouched.

Request example

POST /api/v1/ingredients/analyze
Accept-Language: sv

{
  "focusProductId": "01HW...",
  "withExplanations": false
}

Response example (sv)

{
  "mode": "focus",
  "engineVersion": "v2",
  "actives": [{
    "slug": "retinol",
    "displayName": "Retinol",
    "category": "retinoid",
    "summary": "En retinoid som...", // from cache
    "avoidCategories": ["aha", "bha", ...]
  }]
}
Rule storage
5 Postgres tables, English canonical. Bump ENGINE_VERSION to bust caches.
Seeder
Reads src/ingredients/seed/ingredients-seed.json, upserts idempotently on boot.
Translation LLM
Same OpenAI client as the explanation provider. temperature: 0. Tight prompt forbids adding new info.
Graceful fallback
Any translation failure → return English source. Safety verdict is never LLM-sourced.

4 · What was removed

Surfaces that were misleading by construction

Anything that treated "shelf" as "routine" had to go. The tests for these are deleted; the components are no longer imported.

Gone — shelf-wide "Routine check"

Dashboard RoutineCheckCard  — rendered a fake routine score built from the whole shelf.
/routine-check detail page  — the deep-dive for the same misleading model.
