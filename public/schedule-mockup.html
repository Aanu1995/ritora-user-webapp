What changed in v2

  • No more fixed AM/PM buckets. Each slot has its own clock time (07:30, 14:00, 22:15 — anything the user picks).
  • Per-day accordion list replaces the 7×2 matrix. Each day shows 0..N time slots in chronological order.
  • "Every day" is now a quick action — tap it, pick a time, one slot is added to all seven days in a single transaction.
  • Daypart icons derived from time — sunrise before 12:00, sun midday, moon after 18:00. Pure render logic, no DB column needed.
  • "Today" pill highlights the current day so the user can jump straight to editing.
  • Note indicator (message-square icon) still shows when a slot has notes written.

One flow, two entry points

  • "+ Add time" from a day → same dialog, but only that one day is pre-selected (user can still expand to multiple days).
  • "Every day" quick action → same dialog, all seven days pre-selected.
  • Day chips are always visible — lets the user scale from one day to all seven without leaving the flow.
  • Idempotent on submit: if a day already has a slot at 08:00, it's silently skipped (per the unique (user, day, time) index).
  • Notes + steps are deferred — added only after the slot exists. First commit is time + mode; user opens the slot to fill the rest.

Changes vs v1

  • Time is editable inline — the big 07:30 in the header is a native time input. Change it, save, and the slot moves in the day list.
  • No "Enabled" switch — a slot either exists or it doesn't. Delete replaces disable.
  • Delete action is explicit in the footer, with a confirm dialog to prevent accidental loss.
  • Header daypart icon derives from the time — if you change 07:30 to 14:30, the sunrise icon swaps to noon sun.
  • Notes + steps — unchanged from v1: notes always visible regardless of mode; up to 10 drag-reorderable steps.

How Today reads Schedule

  • Chronological order. All today's slots render in time order (07:30 → 14:00 → 21:00). No AM/PM grouping needed.
  • Daypart icons give instant context — sunrise for early morning, midday sun for afternoon, moon for evening.
  • Manual slots show note callouts + numbered product steps with check-circles for logging completion.
  • AI slots show the "coming soon" placeholder with daypart-aware color (amber/peach/indigo).
  • "Edit →" deep-links to the slot editor for today-only adjustments.
  • Header count — "3 times scheduled" sets the user's expectation before they scroll.
